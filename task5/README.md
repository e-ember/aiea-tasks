## emrlu_A2C_run_logs/
This folder holds the generated logs for 10K steps when running a modified version of the run.py script
on a pre-trained RL model in the Car Racing Gym environment.

## rl_logs/
This folder holds the generated logs for 10K steps when training a Reinforcement Learning model in the Car
Racing Gym environment

## car_racing_RL_logs.png
This graph shows the reward over time while training a Reinforcement Learning model for 10K steps in the Car
Racing Gym Environment

## car_racing_runpy_logs.png
This graph shows the reward over time of a pre-trained RL model for 10K steps in the Car Racing Gym Environment

## rl_car_racing.zip
This is the Reinforcement Learning model trained for a total of 20K steps.

## RL_runpy.csv
This is the CSV containing the raw data shown in the car_racing_runpy_logs.png graph of reward over time

## RL_training_1.csv
This is the CSV containing the raw data shown in the car_racing_RL_logs.png graph of reward over time

## run.py
This is the modified Python file of cruz-control's run.py file used to see how a pre-trained RL model
performs after being trained for 10K steps for another 10K steps in the Car Racing Gym environment.

## RL_alg_1.py
This Python file trains a Reinforcement learning model for 10K steps in the Car Racing Gym environment.
